# CatchSpace

**A smart file dropzone for Windows.** Working on a single monitor is finally easy: no more juggling windows to move files between full-screen apps.

## How it works

1. **Grab the file.** Click and hold the file or folder you want to move, and drag it towards the edge of your screen.
2. **Drop it on the shelf.** CatchSpace pops out automatically. Release the file there and it stays safely on the shelf.
3. **Drag it to its destination.** Switch to your target app (email, Slack, anything), grab the file from the shelf and drop it. The shelf clears itself.

## Features

- **Native on Windows 10 and 11.** Lightweight, never in your way. macOS support is on the roadmap.
- **Not just files.** Drag text snippets, links or images onto the shelf too.
- **Starts with Windows.** Boots silently with your system, always ready when you need it.
